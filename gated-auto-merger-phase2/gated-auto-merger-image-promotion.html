Key Phase 2 Principle

BUILD ONCE, RE-TAG ON GREEN

Phase 1: Build images during early-gate → test → REBUILD on release branch
Phase 2: Build images during early-gate → test → RE-TAG to release tag (no rebuild)

Benefits:
  - Eliminates redundant rebuilds (~65 min saved per component)
  - Guarantees tested images = released images (bit-for-bit identical)
  - Faster time-to-release after tests pass

Re-tag Command Pattern

# For each component image:
skopeo copy \
  --all \
  docker://quay.io/rhoai/${COMPONENT}@sha256:${EARLY_GATE_DIGEST} \
  docker://quay.io/rhoai/${COMPONENT}:${RELEASE_TAG}

# Example:
skopeo copy \
  --all \
  docker://quay.io/rhoai/odh-dashboard-rhel9@sha256:abc123... \
  docker://quay.io/rhoai/odh-dashboard-rhel9:rhoai-3.6-ea.1

# Properties:
#   --all        : copies all architectures (multi-arch manifest list)
#   Idempotent   : safe to re-run (same digest → no-op)
#   Auth         : Quay robot account with write access
