Key Phase 2 Principle

BUILD ONCE, RE-TAG ON GREEN

Phase 1: Build images during early-gate → test → REBUILD on release branch
Phase 2: Build images during early-gate → test → RE-TAG to release tag (no rebuild)

Benefits:
  - Eliminates redundant rebuilds (~65 min saved per component)
  - Guarantees tested images = released images (bit-for-bit identical)
  - Faster time-to-release after tests pass
