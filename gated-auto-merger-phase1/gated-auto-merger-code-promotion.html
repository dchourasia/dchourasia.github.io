Test Classification Tiers

TierScopeMerge ImpactExample Tests
Tier 1: Component-ScopedSingle componentFailure blocks only that componentUnit tests, single-service API smoke tests

Tier 3: Global-ScopedAll componentsFailure blocks ALL mergesFull install/upgrade, cross-product compatibility

Merge Strategy

Stable branch properties:
  - Permanent (never deleted)
  - Protected (only merge orchestrator can push)
  - Uses REGULAR merge (preserves full commit history)
  - NOT squash merge (maintains individual commits)
  - NOT rebase (avoids rewriting history)

Merge orchestrator permissions:
  - Bypass branch protection for stable
  - Automated merge without manual approval
  - Records merge metadata for audit trail
